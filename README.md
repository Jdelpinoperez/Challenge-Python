# Challenge-Python
Proyecto enfocado en el análisis de información de Alura Store Latam en donde podemos revisar el comportamiento en ventas de 4 locales, 
contando con variables como categoria de producto, producto, precio, costo de envio, geolozalización y demás.

En este proyecto se ha realizado concatenaciones de las 4 tiendas, diferenciandolas por una variable que las identifique al momento de realizar la lectura, ello con el 
propósito de tener una vista general y comparativa de cada tienda.

Asimismo, se han creado 4 gráficos, en donde podemos ver el comportamiento de las ventas por categoria / producto y asimismo la calificación que nos brindan los clientes.

Posibles errores:
  Ante posibles errores, se recomienda ejecutar todo el libro desde un inicio, garantizando que todos los pasos se realicen de manera correcta.
